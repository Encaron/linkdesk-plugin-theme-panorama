# Full-Window Hero

Extreme shell theme — the background axis at its limit: sailor-moon.jpg as a full-window hero behind a low mask, chrome stepping aside with translucency (#50.27 end-to-end acceptance; gallery ⑪ realized in the shell)

## What it does

- 1 theme: Full-Window Hero.

## Applying it

- Theme: Settings → Appearance → Theme.

## Install

Open the Plugin Store, find this plugin, and click Install. For offline use, install the `.linkdesk-plugin` package from disk.

## Development

```bash
npm install
npm run dev
npm run lint
npm run verify
npm run build
npm run publish
```

See the repository root `README.md` for the Chinese documentation and the full directory contract.
